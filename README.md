Primary responsabilities of an Operating System

An operating system is the most vital software running on a computer
It manages memory, processes, software, and hardware, allowing users to communicate with the computer without needing to speak it raw machine language.

Fundemental difference between physical Hardware and Software instructions

Hardware is the Tangible, physical components of a computing device, whereas software consists of written instructions / programs telling physical components what to do .
They work together as compliments.

5 internal hardware components

- Motherboard
The central printed circuit board that holds the CPU and essential hardware , serving as the central hub through which all components communicate
- CPU ( Central Processing Unit )
The " brain of the Computer that processes and executes instructions from programs ; performance depends on its clock speed.
-RAM ( Random Access Memory )
Volatile, temporary memory that keeps data immediately accessible to active programs , content clear when powered off.
- Hard Drive
Physical magnetic storage device storing permanent and temporary data ( OS, programs, personal files ).
- Solid state Drive
Fast, non volatile solid -state storage using NAND flash memory technology that safley holds data when powered down

Key operational difference between RAM (volatile) and SSD (non- volatile storage)
Ram - is temporay memory storage that makes information immediately accessible to programs
- stored data is cleared when the computer powers off
SSD - are solid state storage devices based on NAND flash memory technology, so they can store data even when the computer is powered down.
